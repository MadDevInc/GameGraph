O que é o GameGraph

Um mapa de como o seu jogo é feito. A IA lê o projeto Godot e monta processos (ex.: Criar inimigo) com os passos e os arquivos certos de cada um. Você revisa e ajusta aqui. Depois, qualquer agente de IA lê esse mapa antes de trabalhar e segue o jeito do seu projeto.

Para gerar ou atualizar o mapa, use /gamephy no Claude Code. Esta tela serve para ler e editar.

As três áreas

  • Esquerda: Arquivos do projeto. A pasta real do Godot. Clique para abrir um arquivo. Arraste um arquivo para um cartão para ligá-lo.
  • Centro: o grafo. Tem duas vistas: Processos e Arquitetura (botões no topo).
  • Direita: o painel.
    • Inspetor: edita o nó selecionado.
    • Arquivo: mostra o conteúdo do arquivo (código, cena, recurso).
    • Contexto IA: o texto exato que a IA recebe.

Vista Processos

Cada nó é um cartão. Dentro dele estão os arquivos ligados, cada um com o texto que explica para que serve.

  • ■ Processo: como fazer algo no jogo (Criar inimigo, Criar arma…). Tem passos em ordem.
  • ■ Sistema: peças centrais (autoloads, managers, event bus).
  • ■ Entidade: coisas concretas (Goblin, Player). Servem de exemplo.

As setas entre cartões são relações de design (ex.: Criar inimigo → exemplo → Goblin). Se um arquivo aparece em vermelho, ele não existe mais no projeto.

⚠ revisar (borda laranja tracejada): algum arquivo ligado ao nó mudou desde a última revisão. Os passos podem estar velhos. Abra o nó, confira e clique em Marcar como revisado. Os agentes também recebem esse aviso, para não seguirem passos desatualizados.

Vista Arquitetura

Mostra as ligações reais entre os arquivos, detectadas sozinhas, sem precisar da IA:

  • Código (azul): herança e preload. Ex.: goblin.gd herda base_enemy.gd.
  • Arquivos (verde): cena que usa script, instancia outra cena ou referencia um recurso.

Use os botões Código e Arquivos para ligar e desligar cada tipo. Clique num arquivo para ver o conteúdo.

Editar o grafo

  • Selecionar: clique no título do cartão. O Inspetor abre à direita.
  • Mudar: no Inspetor dá para trocar nome, tipo, notas, passos (um por linha) e o texto de cada conexão.
  • Criar: botão + Nó ou duplo clique no espaço vazio.
  • Relacionar: selecione um cartão, clique em Relacionar…, clique no outro cartão e escreva a relação.
  • Apagar: botão Apagar no Inspetor. Os arquivos do Godot nunca são tocados.
  • Mover: arraste o cartão pelo título. Organizar refaz a grade.

Suas edições são protegidas. Quando a IA rodar /gamephy --update, ela não sobrescreve nós que você editou e não recria os que você apagou.

Ligar arquivos

Arraste um arquivo da lista da esquerda para cima de um cartão. O tipo é reconhecido sozinho: .tscn vira cena, .gd vira script e .tres vira dados. Se soltar no espaço vazio, um cartão novo é criado.

Ao clicar num arquivo, a aba Arquivo mostra:

  • .gd: código colorido com busca, classe, herança, exports, sinais e funções;
  • .tscn: árvore de nós da cena, propriedades e recursos;
  • .tres: tipo e valores.

Regras e IA

Em Regras ficam as regras do jogo (ex.: todo inimigo herda BaseEnemy) e as instruções para os agentes. Tudo isso entra no começo do contexto da IA.

Contexto IA mostra o que um agente recebe:

  • sem nó selecionado: o mapa do jogo inteiro (é o arquivo gamegraph-out/CONTEXT.md);
  • com um nó selecionado: o detalhe daquele nó, com árvore de cenas, scripts e dados. Marque incluir código para mandar os scripts completos.

O projeto é observado: se você mudar arquivos no Godot, a tela atualiza sozinha.

Atalhos

  • Rolar: zoom.
  • Arrastar o fundo: mover a tela.
  • Duplo clique no fundo: novo nó.
  • Buscar nó + Enter: vai até ele.
  • Esc: cancela o Relacionar ou fecha este guia.
